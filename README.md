## 功能清单

### 会员端
- ✅ 登录 / 修改密码
- ✅ 主页：身份、职级、收益、阶梯进度一目了然
- ✅ 录单：客户销售 / 自用复购 / 升级补购
- ✅ 我的收益：明细 + 待发放/已发放汇总
- ✅ 我的团队：直属下级列表

### 管理员端
- ✅ 会员管理：添加、编辑、重置密码、禁用
- ✅ 订单管理：查看所有订单
- ✅ 佣金管理：批量标记已发放
- ✅ 数据统计：总销售额、总佣金、待发放等
- ✅ 手动录入股东分红

## 佣金规则（严格执行）

| 情况 | 下单人 | level1（上级星耀） | level2（上级的上级星耀） |
|------|--------|-------------------|------------------------|
| 星享自用 | 0 | 28% | 1.5%（若有星享在链中） |
| 星耀自用 | 0 | 28% | 0（全链星耀，不触发） |
| 星享卖客户 | 23% | 5% | 1.5% |
| 星耀卖客户 | 28% | 1.5% | 0 |
| 星享升级补购 | 0 | 28% | 1.5% |

**绝对红线**：永远不计算第三级佣金，同级星耀间无佣金，无订单无佣金。
